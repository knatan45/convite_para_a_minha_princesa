# Vale Churras — para Victória

Uma experiência romântica interativa feita em HTML, CSS e JavaScript puro.

## Como abrir

1. Descompacte ou abra esta pasta no VS Code.
2. Abra `index.html` diretamente no navegador. Não é necessário instalar nada nem iniciar servidor.
3. Para editar textos ou interações, use `index.html` e `script.js`; para cores e layout, use `style.css`.

No voucher, toque em **Imprimir / salvar em PDF**. Na tela de impressão do navegador, escolha **Salvar como PDF** ou uma impressora. O layout de impressão foi preparado para destacar apenas o voucher.

A página não inicia áudio e não depende de imagens ou bibliotecas externas. As fontes da marca são carregadas de Google Fonts quando há conexão; sem internet, entram fontes de sistema semelhantes.
